# RetailPulse – AI-Powered Customer Analytics & Demand Forecasting Platform

# Project Overview
RetailPulse is a retail data analytics project built using the Online Retail II dataset. It explores recorded sales, product performance, customer purchasing behaviour, and country-level sales trends.

## Tools Used
- Python
- Pandas
- Power BI
- Excel / CSV datasets

# Key Features
- Analysis of over 1 million retail transaction records
- Data cleaning and preparation
- Sales and product performance analysis
- Customer segmentation analysis
- Interactive Power BI dashboards with KPI cards, charts, and filters

# Project Files
- `01_load_data.py` – Python data-loading and preparation script
- `retailpulse_analysis_ready.csv` – Analysis-ready dataset
- `retailpulse_cleaned.csv` – Cleaned dataset
- `RetailPulse_Dashboard.pbix` – Interactive Power BI report
- `RetailPulse_Final_Report.pdf` – Exported report

# Important Note
This version focuses on data analytics and visualization. It does not implement machine-learning forecasting, churn prediction, or actual inventory optimization.

# Conclusion
The project demonstrates how retail transaction data can be prepared, analyzed, and presented through interactive dashboards to support business understanding and decision-making.
