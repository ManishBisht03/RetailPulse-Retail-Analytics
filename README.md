# RetailPulse – Retail Sales & Customer Analytics

## Project Overview
RetailPulse is a retail data analytics project that analyzes sales transactions, product performance, customer purchasing behavior, and country-level sales using Python, Power BI, and Streamlit.

The project transforms retail transaction data into meaningful business insights through data cleaning, exploratory data analysis, interactive dashboards, and KPI reporting.

## Objectives
- Analyze monthly sales trends and recorded sales performance.
- Identify top-performing products and countries.
- Understand customer purchasing patterns and recorded sales.
- Build interactive dashboards to support data-driven decisions.

## Tools & Technologies
- **Python:** Data cleaning and analysis
- **Pandas:** Data processing and aggregation
- **Power BI:** Interactive dashboards and visual reporting
- **Streamlit:** Web-based analytics dashboard
- **GitHub:** Source code management and project hosting

## Key Findings
- Analyzed over 1 million retail transaction records.
- Identified 5,305 unique products and 43 countries.
- Identified 5,942 customers with available customer IDs.
- Examined monthly sales trends, product performance, country-level sales, and customer metrics.

*Note: Customer-level results exclude transactions with missing customer IDs. Recorded sales include negative transactions and returns; they should not be interpreted as profit.*
